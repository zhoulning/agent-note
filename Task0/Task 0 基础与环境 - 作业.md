## 实验 1-4

### 个人运行情况

实验 1-4 需要：

1. 工作流路线：Kimi K3 改写 + 通义万相生图
2. 原生路线：Gemini 或 OpenAI 图像模型

本人当前：

- Kimi 账号无 `kimi-k3` 权限
- 无 Gemini / OpenAI 图像 Key

因此**本人未完成该实验的正式运行**。

### 实验目的

让同一句口语化中文需求走「工作流改写」与「原生一次出图」两条路线，对照观察：

1. 工作流中「改写」节点会不会弄丢或篡改用户原始需求；
2. 原生图像模型能不能自己理解口语化中文并直接出图。

### 官方参考结果（仓库历史验收，非本人运行）

参考目录：`Task0/实验1-4官方参考结果/real_20260821T040450Z`  
来源：书稿仓库 `chapter1/image-gen-workflow/validation/real_20260821T040450Z`  
运行规模：5 句需求 × 3 条路线，共 15 次，全部成功

官方运行的主要发现：

1. **具体需求（如耳机海报）**：工作流改写节点可能把用户指定文案丢进 `negative_prompt`，导致成图没有文案；两条原生路线都能较好保留文案。
2. **宽泛需求（如 AGI 后程序员场景）**：改写节点会做场景具象化；但更强的原生模型也能自己补出叙事。
3. 工作流路线中的改写节点更像「翻译 + 适配」，不是真正的智能决策；原生模型能力越强，改写节点的信息增益越有限。

### 结论（基于官方结果理解）

工作流路线中「改写」节点的价值取决于下游生图模型的能力短板；当原生图像模型已经能理解口语化中文并直接出图时，改写节点既可能带来场景增益，也可能弄丢用户原始约束。这说明适配层不是越复杂越好，而应服务于模型当前的真实短板。

> 说明：以上结果来自书稿配套仓库的官方验收记录，不是本人本地运行结果；本人因缺少 K3 与图像模型 Key 未能复现。


## 实验 7-1


### 实验目的

验证传统强化学习（表格型 Q-learning）在带有隐藏机制的寻宝游戏中的学习过程：需要多少经验才能掌握规则，以及学会后是否稳定。

### 实验结果

| 指标 | 结果 |
| --- | --- |
| 训练时间 | 4.77 秒 |
| Q-table 状态数 | 142 |
| 训练胜率 | 45.10% |
| **评估胜率** | **100.00%** |
| 平均奖励 | 243.0 |
| 平均步数 | 12.0 |

学习曲线（滑动窗口胜率）：

| Episodes | Victory rate | Q-table | epsilon |
| ---: | ---: | ---: | ---: |
| 1000 | 0.3% | 123 | 0.606 |
| 2000 | 0.0% | 123 | 0.368 |
| 3000 | 0.1% | 126 | 0.223 |
| 4000 | 0.1% | 127 | 0.135 |
| 5000 | 0.1% | 128 | 0.100 |
| 6000 | 55.9% | 137 | 0.100 |
| 7000 | 97.0% | 138 | 0.100 |
| 8000 | 99.6% | 138 | 0.100 |
| 9000 | 99.8% | 139 | 0.100 |
| 10000 | 98.1% | 142 | 0.100 |

### 结论

1. **传统 Q-learning 样本效率很低**：前 5000 局几乎无法获胜，直到约 6000 局才突然开窍。
2. **学会后非常稳定**：评估阶段 100 局全部获胜，说明一旦掌握状态-动作映射，策略可以稳定复用。
3. **这是黑盒式记忆学习**：Q-table 记录的是「在某状态选某动作的期望收益」，而不是对游戏规则的语言化理解。
4. 这为后续与 LLM 的对比提供了基线：LLM 有望通过推理在远少于数千局的情况下完成任务。
