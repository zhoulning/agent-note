
感知工具 MCP 服务器 —— 工具清单（共 54 个）
========================================================================

【搜索】(4 个)
------------------------------------------------------------------------
  web_search                 使用 DuckDuckGo 进行网络搜索（免费，无需 API Key）  [联网]
  knowledge_base_search      在本地知识库目录中做全文检索
  download                   从 URL 下载文件到本地（含大小/覆盖保护）  [联网]
  google_search_enhanced     Google Custom Search，失败时回退 DuckDuckGo  [联网；Google API 需 GOOGLE_API_KEY，未配置则自动回退]

【多模态理解】(19 个)
------------------------------------------------------------------------
  webpage_reader             抓取并提取网页正文/链接  [联网]
  webpage_read_enhanced      增强版网页正文提取  [联网]
  document_reader            读取 PDF/DOCX/PPTX 文档内容
  pdf_extract                提取 PDF 文本（支持页码范围）
  docx_extract               提取 Word（DOCX）文档内容
  pptx_extract               提取 PowerPoint（PPTX）内容
  csv_parse                  解析 CSV 表格数据
  image_parser               解析图片（可选 LLM 视觉分析）  [use_llm 需视觉模型 API]
  image_ocr                  对图片做 OCR 文字识别  [需安装 tesseract]
  image_analyze              用视觉模型分析图片内容  [需视觉模型 API]
  image_metadata             读取图片 EXIF 等元数据
  video_parser               提取视频元数据/采样帧
  video_keyframes            从视频抽取关键帧
  video_analyze              用视觉模型分析视频内容  [需视觉模型 API]
  audio_transcribe           用 Whisper 将音频转写为文本  [需安装 whisper]
  audio_metadata             读取音频文件元数据
  audio_trim                 裁剪音频到指定时间区间
  youtube_transcript         提取 YouTube 视频字幕  [联网]
  youtube_download           下载 YouTube 视频  [联网]

【文件系统】(3 个)
------------------------------------------------------------------------
  file_reader                读取文件内容（支持编码与截断）
  grep                       在目录中按正则搜索文件内容
  text_summarizer            对长文本做摘要（抽取式/截断，占位实现）
